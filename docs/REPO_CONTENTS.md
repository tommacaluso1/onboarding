# Repository Contents

If you do not see files in your Git UI, make sure you are on the latest branch and that you have pulled the newest commits.

## Files you should see

- `README.md` — Overview and step-by-step instructions.
- `windows/onboarding.ps1` — Windows app installer script.
- `windows/run-onboarding.cmd` — Double-click launcher for Windows.
- `mac/onboarding.sh` — macOS app installer script.
- `mac/Onboarding.command` — Double-click launcher for macOS.

## Quick “What do I run?”

- **Windows:** run `windows/run-onboarding.cmd` as Administrator.
- **macOS:** double-click `mac/Onboarding.command`.
